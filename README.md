# Linux System Administration & Network Troubleshooting Lab

## Environment
- Ubuntu 22.04.5 LTS (WSL)
- Bash Shell

## Practical Tasks
1. Linux user and group management
2. File and directory permissions
3. Process monitoring and termination
4. Service management using systemctl
5. Network troubleshooting using ping, ip, nslookup and curl
6. Log monitoring and filtering using grep, tail and less
7. Bash automation scripts
8. Cron job scheduling

## Bash Automation
- system_info.sh – Displays system information.
- health_check.sh – Checks uptime, disk, memory and cron status.

## Cron Automation
Scheduled the health-check script to run every minute and verified automatic log generation.

## Learning Outcomes
- Basic Linux system administration
- Process and service management
- Network troubleshooting
- Log analysis
- Bash scripting and task automation
